# Vault - RETH Second Brain

Organización del conocimiento del proyecto RETH para trabajar con CodeGraph y Obsidian.

## Estructura

### Raw/
Notas sin procesar, ideas, archivos brutos.
- Sube aquí notas de reuniones, ideas nuevas, archivos temporales
- No te preocupes por el orden - solo captura

### Wiki/
Conocimiento estructurado y organizado.
- **knowledge/** - ADRs, auditorías, contexto de agentes
- **docs/** - Documentación del proyecto (requisitos, backlog, guías)
- **architecture/** - Canvas de arquitectura y diagramas

### Output/
Documentos generados, investigaciones, planes.
- Documentos finales
- Investigaciones completadas
- Planes de implementación
